🏥 คู่มือการติดตั้งและใช้งาน Medical Text Expander (สำหรับวอร์ดพยาบาล)
========================================================================

【วิธีนำไปติดตั้งในเครื่องอื่น (ง่ายมาก 1 คลิกเสร็จ)】
1. คัดลอกโฟลเดอร์นี้ หรือแตกไฟล์ ZIP ใส่ Flash Drive (หรือวางในไดรฟ์แชร์ของวอร์ด)
2. นำไปเปิดในเครื่องคอมพิวเตอร์ที่ต้องการติดตั้ง
3. ดับเบิ้ลคลิกที่ไฟล์:
      👉 "Setup_Medical_Expander.bat"
4. รอ 3 วินาที โปรแกรมจะ:
   - คัดลอกตัวเองไปไว้ที่ C:\PhisApp\Medical_Text_Expander
   - สร้างไอคอนบนหน้าจอ Desktop ให้อัตโนมัติ
   - ตั้งค่าให้เปิดโปรแกรมอัตโนมัติทุกครั้งที่เปิดเครื่องคอมพิวเตอร์ (Startup)
   - เปิดโปรแกรมพร้อมทำงานทันที!

------------------------------------------------------------------------
【ความต้องการของระบบ】
- ทำงานได้บน Windows ทุกรุ่น (Windows 7, 8, 10, 11)
- ไม่ต้องติดตั้งโปรแกรมเสริมใดๆ ทั้งสิ้น (เป็น .NET Standalone 100%)
- ขนาดไฟล์รวมไม่ถึง 1 MB เบาเครื่องมาก ไม่กินแรม ไม่หน่วง e-PHIS

------------------------------------------------------------------------
【วิธีตั้งค่าให้ข้อมูลเตียง 1-30 และตัวเตือนหัตถการ ซิงค์กันทั้งวอร์ด (ทุกเครื่องเห็นพร้อมกัน)】
1. เลือกคอมพิวเตอร์หลัก 1 เครื่องในเคาน์เตอร์วอร์ด แล้วสร้างโฟลเดอร์แชร์ในวง LAN
   (เช่น \\NURSE-PC01\PhisShared\ หรือไดรฟ์กลาง Z:\WardNotes\)
2. ในโปรแกรม Medical Text Expander ให้กด F7 (ข้อมูลรายเตียง)
3. กดปุ่ม "🌐 ตั้งค่าแชร์ในวอร์ด" ด้านล่าง
4. ติ๊ก "เปิดใช้งานการแชร์ข้อมูลในวอร์ด" แล้วกด "เลือกโฟลเดอร์" ไปที่โฟลเดอร์แชร์
5. ทำแบบเดียวกันนี้ในทุกเครื่องในวอร์ด
   ผลลัพธ์: เมื่อพยาบาลเตียง 1 บันทึกโน้ต หรือตั้งเวลาเตือน เครื่องอื่นๆ จะเห็นตรงกันทันที!

------------------------------------------------------------------------
【คีย์ลัดสำคัญที่ต้องรู้】
• F8       : เปิดคลังเทมเพลต (Template Palette) เลือกลากวาง Nurse Note ได้ทันที
• F7       : เปิดสมุดบันทึกผู้ป่วยรายเตียง 1-30 (Bed Notes)
• Alt+T    : เปิดกระดานเตือนเวลาทำหัตถการ (Ward Task Reminders)
• Alt+C    : เปิดเครื่องคิดเลขคำนวณ SOS, ยา, ABG, อัตราหยดน้ำเกลือ
• .b1-.b30 : พิมพ์ในหน้า e-PHIS เช่น ".b05" แล้วเคาะ Spacebar จะดึงข้อมูลเตียง 5 มาพิมพ์ให้อัตโนมัติ
• Ctrl+Enter : วางข้อความจากสมุดบันทึกเตียงลงหน้าจอ e-PHIS ที่เปิดค้างอยู่ทันที
