โปรแกรมช่วยเหลือแพทย์ พยาบาล และบุคลากรทางการแพทย์ ในการบันทึกเวชระเบียนผู้ป่วย (e-PHIS)
พร้อมระบบวิเคราะห์ผลก๊าซในเลือด (ABG), ตัวเตือนหัตถการรายเตียงค้างจอ, และประวัติเตียงย้อนหลัง

1. ฟังก์ชันใหม่ล่าสุด (NEW FEATURES)
--------------------------------------------------------------------------------

[1] 🫁 ระบบวิเคราะห์ผลเจาะก๊าซในเลือดอัตโนมัติ (ABG Interpreter)
- กดปุ่มลัด Alt + C แล้วเลือกแท็บ "แปลผลก๊าซในเลือด (ABG)" หรือกดปุ่ม "แปลผล ABG" ใน F7
- ใส่ค่า pH, PaCO2, HCO3, PaO2, FiO2
- โปรแกรมจะวิเคราะห์ภาวะสมดุลกรด-ด่างให้อัตโนมัติ:
  * Acidemia / Alkalemia
  * Metabolic Acidosis พร้อมคำนวณการชดเชยด้วย Winter's Formula:
    Expected PaCO2 = (1.5 x HCO3) + 8 (+/- 2)
  * Metabolic Alkalosis: Expected PaCO2 = 0.7 x (HCO3 - 24) + 40 (+/- 2)
  * Respiratory Acidosis / Alkalosis (แยกภาวะเฉียบพลัน Acute และเรื้อรัง Chronic)
  * ประเมิน Oxygenation & ARDS (PaO2/FiO2 ratio ตามเกณฑ์ Berlin Definition)
  * คำแนะนำและการพยาบาล (Nursing Actions): เฝ้าระวังทางเดินหายใจ, ปรับ Vent, ระวัง K+
- มีปุ่มเคสตัวอย่างพบบ่อย 8 เคสให้กดศึกษาและทดสอบ
- กดปุ่มเดียวส่งผลและข้อความสรุปไปวางใน Nurse Note (e-PHIS) หรือแทรกลงเตียงปัจจุบันได้ทันที

[2] ⏰ ระบบตัวเตือนเวลาทำหัตถการรายเตียง (Ward Care & Task Reminders)
- กดปุ่มลัด Alt + T หรือคลิกปุ่ม "ตัวเตือนหัตถการ (Alt+T)"
- หน้าต่างแสดงผลเป็น "แผ่นกระดาษโน้ตลอยค้างหน้าจอ (TopMost Sticky Notepad)"
  มองเห็นงานค้างของแต่ละเตียงตลอดเวลา ไม่ถูกหน้าต่างอื่นบัง
- ระบบแยกสีเตียงแตกต่างกันชัดเจน (10 เฉดสีแยกตามเลขเตียง/โซน):
  * แต่ละเตียงมีธีมสีเฉพาะตัว พร้อมแถบสีข้างการ์ดและป้ายเลขเตียงสีเฉพาะ
  * ปุ่มเตียงในหน้าต่าง F7 มีสีกรอบและสีพื้นหลังตามธีมสีประจำเตียงสวยงาม
- ระบบแจ้งเตือนสีเหลืองส้มเมื่อใกล้ถึงเวลา (ภายใน 15 นาที):
  * การ์ดเตือนและปุ่มเตียง F7 เปลี่ยนเป็นสีส้มอำพัน [⚠️ อีก Xน.] เตือนให้เตรียมตัวล่วงหน้า
- ระบบกระพริบเตือนสีแดง (Blinking Alert) เมื่อถึงเวลาแล้ว / เกินกำหนด:
  * การ์ดบนแผ่น Sticky Pad และปุ่มเตียงในหน้าต่าง F7 จะกระพริบสีแดงสลับขาว [🚨 ถึงเวลา!] ทันที!
- แสดงเวลานับถอยหลังชัดเจนโดยไม่ต้องแสดงวินาทีให้รกตา เช่น [อีก 14 นาที (11:30 น.)], [⏰ ถึงเวลาแล้ว!]
- แสดงข้อความยาวได้ครบถ้วน ไม่ถูกตัดขาด (Multi-Line Auto-Wrap): กล่องการ์ดปรับความสูงอัตโนมัติ
- ปุ่มกดแก้ไขแจ้งเตือนด่วน (✏️) บนการ์ดทุกใบ: กดแก้ไขรายละเอียด เตียง หรือเปลี่ยนเวลาได้ทันที
- เมนูคลิกขวาบนรายการ: แก้ไข, เลื่อนเวลา +15น./+30น./+1ชม., เปิดเตียง F7, เคลียร์เสร็จ, ลบ
- ดับเบิลคลิกที่รายการ เพื่อเปิดไปหน้าบันทึกเตียงนั้นใน F7 ทันที
- ระบบเลือกรอบเวลาตามเข็มนาฬิกา ทุก 1 ชั่วโมง ตลอด 24 ชม. (อัปเดตใหม่):
  * มีปุ่มเลือกรอบเวลาครบทั้ง 24 ชั่วโมง จัดหมวดหมู่ตาม 3 ผลัดเวรพยาบาล:
    - ☀️ เวรเช้า (08:00 - 15:00 น.): [08:00] [09:00] [10:00] [11:00] [12:00] [13:00] [14:00] [15:00]
    - 🌅 เวรบ่าย (16:00 - 23:00 น.): [16:00] [17:00] [18:00] [19:00] [20:00] [21:00] [22:00] [23:00]
    - 🌙 เวรดึก (00:00 - 07:00 น.): [00:00] [01:00] [02:00] [03:00] [04:00] [05:00] [06:00] [07:00]
  * ชิปปรับเศษนาทีด่วน: [:00 ตรง] [:15 น.] [:30 น.] [:45 น.] [ตอนนี้] [+15น.] [+30น.]
  * โหมดนับเวลาล่วงหน้า พร้อมชิปด่วน +15น., +30น., +45น., +1ชม., +2ชม., +4ชม.
- ปุ่มลัดชื่อหัตถการด่วน (นำเวลาออก แยกอิสระจากเวลา - อัปเดตใหม่):
  * [🩺 วัด V/S & SOS ซ้ำ]
  * [📞 โทรตามผล X-ray / Lab ด่วน]
  * [🩸 เจาะ DTX ก่อนอาหาร]
  * [💧 เตรียมเปลี่ยนถุง IV]
  * [🩹 ตรวจแผล / ให้ยา ATB]
  * [🩸 สังเกตอาการหลังให้เลือด]
  * [🧪 วัด I/O & ปัสสาวะ]
  * [💊 ประเมินอาการหลังให้ยา]
- ช่องพิมพ์รายละเอียดงานที่ต้องทำ เด่นชัดและใหญ่ขึ้น (อัปเดตใหม่):
  * ขยายช่องพิมพ์ให้ใหญ่ขึ้น ตัวอักษรขนาด 11pt ชัดเจน รองรับการพิมพ์หลายบรรทัด
- ดูและแก้ไขจาก F7: ในปุ่ม "ตั้งเตือนหัตถการเตียงนี้" จะมีรายการเตือนที่รออยู่ของเตียงนั้นให้กดแก้ไขได้ทันที
- เมื่อถึงเวลากำหนด จะมีเสียงเตือน + แถบข้อความบอลลูนมุมล่างจอ + ดึงหน้าต่างขึ้นมากะพริบเตือน
- รายการเตือนจะถูกบันทึกเก็บไว้ ไม่หายแม้ปิดโปรแกรมหรือรีสตาร์ตคอมพิวเตอร์

[3] 📜 ระบบประวัติเตียงย้อนหลังและกู้คืนข้อมูล (Bed History & Recovery)
- ป้องกันข้อมูลสูญหาย 100% แม้พยาบาลเผลอกดปุ่มล้างเตียงผิด หรือต้องการดูข้อมูลผู้ป่วยรายก่อนหน้า
- ระบบถ่ายสำเนาข้อความเก็บไว้ในโฟลเดอร์ history อัตโนมัติทุกครั้งก่อนกด Clear เตียง หรือเปลี่ยนเตียง
- กดปุ่ม "📜 ประวัติเตียงย้อนหลัง" ในหน้าต่าง F7 เพื่อดูไทม์ไลน์ย้อนหลังทั้งหมด
- มีหน้าต่างพรีวิวอ่านข้อความย้อนหลังได้อย่างปลอดภัย
- กดปุ่ม "📥 กู้คืนข้อมูลมายังเตียงนี้" เพื่อดึงข้อความกลับมาทำงานต่อได้ทันทีในคลิกเดียว

2. ตารางสรุปปุ่มลัด (SHORTCUT KEYS)
--------------------------------------------------------------------------------
- F7 หรือ Alt + B             : เปิดหน้าต่างบันทึกข้อมูลผู้ป่วยรายเตียง (เตียง 1 - 30)
- Alt + T หรือ Ctrl+Shift+T  : เปิดแผ่นเตือนหัตถการลอยค้างหน้าจอ (Sticky Pad)
- Alt + C หรือ Ctrl+Shift+C  : เปิดเครื่องคิดเลขและวิเคราะห์ผล ABG / SOS / ยาดริป
- F8 หรือ Ctrl + Shift + M   : เปิดคลังเทมเพลตมาตรฐานการพยาบาล (Focus DAR)
- .b1 ถึง .b30 + Space/Tab    : ขยายข้อความของเตียงนั้นไปวางใน e-PHIS ทันที
- Ctrl + Enter (ในหน้า F7)    : วางข้อมูลเตียงปัจจุบันลงในโปรแกรม e-PHIS ทันที
- PageUp / PageDown           : สลับเตียงก่อนหน้า / เตียงถัดไป
- Ctrl + หมุนลูกกลิ้งเมาส์      : ปรับขนาดตัวอักษร ย่อ/ขยาย เพื่อความสบายตา
- Esc                         : ปิด/ซ่อนหน้าต่างกลับลง System Tray

--------------------------------------------------------------------------------
3. การคำนวณและประเมินค่าวิกฤต (Alt + C)
--------------------------------------------------------------------------------
1. SOS Score (MEWS)      : ประเมินคะแนนสัญญาณเตือนวิกฤต 7 ตัวแปร พร้อมเกณฑ์ปฏิบัติ
2. MAP & Shock Index     : คำนวณ MAP (เตือนวิกฤตเมื่อ < 65) และ Shock Index (> 0.9)
3. IV Infusion & Drop    : คำนวณ ml/hr, หยด/นาที, วินาทีต่อหยด และเวลาที่น้ำเกลือหมดถุง
4. Inotrope / Drug Drip  : คำนวณ Levophed, Dopamine, Dobutamine, Cardene, RI, Cordarone
5. Renal (CrCl) & BMI    : คำนวณ CrCl แยกชาย/หญิง, CKD Stage 1-5, เตือนการปรับขนาดยา
6. ABG Interpreter       : วิเคราะห์สมดุลกรดด่าง, Winter's formula, ARDS severity

--------------------------------------------------------------------------------

--------------------------------------------------------------------------------

- เลือก "🌐 เชื่อมต่อและซิงค์ข้อมูลในวอร์ด"
- ใส่โฟลเดอร์ส่วนกลางของหอผู้ป่วย เช่น \\192.168.134.1\Users\Public\share\ward_bed_notes
- กด "💾 บันทึกและเชื่อมต่อ" ข้อมูลจะเชื่อมโยงกันทุกเครื่องในวอร์ดแบบเรียลไทม์
